How to read this, and what it leaves out

An early win is a game decided before turn 4. A means line that stops is a game ending, not a side vanishing. Stocks are read at the end of a turn; orders are counted when given and never added to stocks. An upgraded building is listed as its own building too.

The computer player does not yet count its own generals and aircraft when choosing attacks: with that on, more games ended early, so it is held back. Two sides of the game were therefore not tested: those attack choices, and any human.
