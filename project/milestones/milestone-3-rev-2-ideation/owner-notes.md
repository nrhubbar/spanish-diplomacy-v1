# Milestone 3 Revision 2: owner's notes (verbatim, 20 Nov 2026)

> Internal. Nothing here may be imported into or rendered by the player-facing application.

1. Malaga is not connected to friendly territories, it is surrounded by unfriendly sub-terrs. So even though there is a friendly subterr that is on the boundary, the army isn't in that, so shouldn't be able to move through unfriendly subterrs to get there.
2. Balance: Northern is too strong, they should have 1-2 less armies. Southern is also pretty strong, I think we should remove their army from mallorca.
3. Fighters and Bombers should act a lot more like regular units, they should have unique order types that they can recieve. As well as, when they're involved in combat lets iterate on what sort of special effects on the die roll they get
4. Zooming in more than 250% should show the subterr boundaries
5. Madrid shouldn't be able to build a port, each sub terr needs a list of buildings it can build.
6. Re-work rail, in rev 1 I said assume that neighboring sub-terrs always have connected rail, I actually think this needs to be treated as a graph, where subterrs may or may not be connected to their neighbors with roads or rail roads, and then those roads/rail roads can be upgraded or built. Certain connections between sub-terrs should be more or less expensive based on terrain modifiers. This will have implications on how we calculate rail movement, but I think its basically there has to be a path through the subterrs from the source Territory to the Desination Territory, e.g. Not that this is how the rail was historically, but lets say madrid and toledo are connected, and toledo is connected to Extremadura and Valencia; then a troop shouldn't be able to move 2 to Andalucia FOR EXAMPLE. So lets iterate on the rail mechanic to be historically accurate. The visual of the rail line is perfect!!
6.a: Thinking about road mechanics, because right now it is essentially free for armies to move between any territory, when infact some are harder to get to than others. So what I am thinking is that if there is no road connected subterrs between territories, then only infantry can cross. If there is a road, then all units can cross. If there is a road and there are truck units making the same move, then it should kinda act like a rail move. Its too cheap right now to move between the norther mountainous regions. Again, these things should be baked into the map data, so when we model 7yrs war, or 30yrs war, or ww1 we can sort of create the conditions that drive armies one way or another, regardless of the era.
7. Bomber Raids Order Lines on the map should point to the destination subterr
8. There should be a "Map Layers" tool bar at the bottom on desktop to enable players to toggle what they want to see on the map.
9. When looking at the Territory Info I should be able to quickly glean with a queue/progress bar whats actively being recruited or built, how many turns are left, and what's left in the queue. Same for buildings across the subterrs in the territory.
10. In the turn resolution phase, the summary panel below "What Happened" each section should be grouped by player.
11. Improve the replinish UX, its hard to give a group of soldiers replinishment orders. Also, slightly related, when I go to give a group of units orders, once done it goes back to select all, It should go to select none.
12. Dug In pips should still be 1/2/3 (this is dug in level), but they should affect the die roll 2/4/6
13. Building a factory should also require man power.
14. If a party withdraws from a contested territory then it should automatically go to the player with units still in the terr. Similarly, some of the outcomes that result in the defender(or attacker) being eliminated, leave the territory contested. If only one party has units in a territory, then it should become un-contested.
15. Orders tab needs improved CX: Basically we have this tab on the right called "Orders" and everything renders within that. Orders should show all of the active orders, recruitements, buildings in progress that have been submitted so-far that turn (with group-by options like: show all unit orders, show all building queues, show all recruits; group by region). We also need a Territory Info, where when a user clicks on a territory the pane on the right goes from Orders to a Territory Info pane titled the Territory name they clicked on. Here will have the Units, Buildings, Recruit tabs we're familiar with. Clicking the "Build in ___" should open a card in that pane with building queue options. Each sub-terr has a expandable card in the Territory Info/buildings view. When zoomed in and clicking on a subterr, it should bring up that Territory Info Pane in the Buildings view, with that subterr's building queue card expanded. Territory Info Pane should also have a Production tab, that shows how that terr is generating the man power and funds that it is
16. Clikcing on the funds chip should show me a balance view that has rows for each terr belonging to that player, including contested. So each row would be like Madrid: +3, Andalucia: +4 (-4: Contested). Same for the manpower chip.
17. Are there more agentic tools, skills, agents, etc. that I should install to help you with the development of this game?

Owner's ask: a reviewable artifact like the one used at the start of Rev 1 (fewer widgets), with UI samples. Be critical of the ideas; ground them in what makes a game good, cohesive and immersive, not muddied. Research both historically and game-design-wise.
