# Map asset provenance

## `iberia-registered.svg`

Runtime territory geometry and interaction mask, generated by `scripts/register-geography.mjs` from the geoBoundaries gbOpen Spain ADM1 dataset. The source is pinned to geoBoundaries revision `9469f09`; its source authority is Spain's Instituto Geográfico Nacional.

- Source: https://www.geoboundaries.org/api/current/gbOpen/ESP/ADM1/
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)
- Attribution: © geoBoundaries; source boundary data from Instituto Geográfico Nacional, Spain
- Changes: simplified source polygons are fitted into the local terrain projection, assigned stable game IDs, and serialized into the game's view box

`iberia.svg` is the original MapChart prototype geometry retained as an implementation reference. It is not loaded by the runtime.

## `spain-topo.png` and `spain-topo.jpg`

Local Iberian relief crop used as the non-interactive terrain texture. `spain-topo.jpg` is the optimized runtime derivative of the PNG source. The relief source is Maps-For-Free, released under CC0 and built from public SRTM/GTOPO30 elevation data and VMap0 geographic layers.

- Source: https://maps-for-free.com/about.html
- License: Creative Commons CC0
- Runtime use: local raster only; the game does not call an external map service

The game applies a neutral grayscale treatment at runtime. Faction control, borders, cities, counters, and orders are separate project-owned interaction layers.

`iberia-relief-aligned.jpg` is the 1024 px terrain crop. `iberia-relief-registered.jpg` is its boundary-cleaned runtime derivative, and `iberia-relief-registered-height.jpg` is the grayscale displacement and bump derivative. `iberia-neutral-surroundings.png` is generated from the registered open boundary geometry. All are local assets; the game requires no map service at runtime.
